## 📖 Sobre o Projeto

Landing page educativa que explica os 7 componentes obrigatórios para um PC funcionar, desenvolvida com foco em design responsivo e experiência do usuário.

## 🎨 Características

- ✅ Design moderno e profissional
- ✅ Totalmente responsivo (mobile, tablet, desktop)
- ✅ Animações e transições suaves
- ✅ Navegação intuitiva
- ✅ Conteúdo educativo estruturado

## 🎓 Componentes Abordados

1. Processador (CPU)
2. Placa-mãe
3. Fonte de Alimentação
4. Memória RAM
5. Armazenamento (HDD/SSD)
6. Sistema de Resfriamento
7. Sistema Operacional
